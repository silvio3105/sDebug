About

Simple Debug library is frameworkless library written in C++. It provides three debug levels - verbose, info and error. Each level can be enabled or disabled during compile time. User have to redefine output function in application layer. The library is encapsulated in sDebug namespace. Examples can be found in Examples folder.

Levels

Library supports three debug levels:

  • Verbose: Debug level for fine details during application runtime, eg., measured temperature each second.
  • Info: Debug level for events, actions and notifications/warnings, eg., if measured temperature is below minimum or above maximum.
  • Error: Debug level for errors during application runtime, eg., if temperature sensor init fails.

It is possible to enable each level.

Usage

Include sDebug.hpp in each file where debug is needed. Inside Main.cpp redefine function void sDebug::out(const char* string, const uint16_t len) and pass string and len to function for final print(eg., RTT, UART etc...).

Compile flags

  • sDEBUG: Enable debug prints for whole project. This flag is "main switch" all debug prints.
  • sDEBUG_VERBOSE: Enable verbose debug level for whole project. Does not enable info or error levels.
  • sDEBUG_INFO: Enable info debug level for whole project. Does not enable error level.
  • sDEBUG_ERROR: Enable error debug level for whole project.
  • sDEBUG_BUFFER_SIZE={n}: Set printf buffer size to n bytes. If not provided, buffer size will be set to default value.
  • sDEBUG_STACK_PRINTF: Use buffer on stack for printf function.

Enable/Disable debug

Enable debug levels with snippets:

  • sDEBUG_ENABLE_VERBOSE({module}): Enable verbose debug level for module(eg., ILPS22QS).
  • sDEBUG_ENABLE_INFO({module}): Enable info debug level for module(eg., ILPS22QS).
  • sDEBUG_ENABLE_ERROR({module}): Enable error debug level for module(eg., ILPS22QS).

Those snippets will create static function aliases for each debug level. Disable debug levels with snippets:

  • sDEBUG_DISABLE_VERBOSE({module}): Disable verbose debug level for module(eg., ILPS22QS).
  • sDEBUG_DISABLE_INFO({module}): Disable info debug level for module(eg., ILPS22QS).
  • sDEBUG_DISABLE_ERROR({module}): Disable error debug level for module(eg., ILPS22QS).

When debug level is disabled, prints for disabled level are redirected to dummy function and removed later in compile/build process.

Print functions

Library provides three functions for each debug level:

  • _PRINT: For constant strings without string length - _PRINT("String\n");
  • _PRINTN: For constant strings with string length - _PRINTN("String\n", 7);
  • _PRINTF: For formatted strings - _PRINTF("String %u\n", 10);

Function format is {module}_PRINT(N/F){_level} where module is provided with sDEBUG_ENABLE. For example, if all levels are enabled for ILPS22QS module, then functions will be:

  • For verbose level: ILPS22QS_PRINT, ILPS22QS_PRINTN and ILPS22QS_PRINTF.
  • For info level: ILPS22QS_PRINT_INFO, ILPS22QS_PRINTN_INFO and ILPS22QS_PRINTF_INFO.
  • For error level: ILPS22QS_PRINT_ERROR, ILPS22QS_PRINTN_ERROR and ILPS22QS_PRINTF_ERROR.
